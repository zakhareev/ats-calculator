# Калькулятор авиабезопасности

Веб-приложение на TypeScript (Vite): прогноз показателей авиационной транспортной системы
методом системной динамики (8 дифференциальных уравнений, метод Рунге — Кутты 4-го порядка).

## Структура

| Файл | Назначение |
|---|---|
| `src/model.ts` | расчётное ядро: уравнения, коэффициенты, метод Рунге — Кутты |
| `src/data.ts` | названия переменных и факторов, готовые сценарии |
| `src/chart.ts` | SVG-график с подсказкой |
| `src/main.ts` | интерфейс и связь с моделью |
| `src/style.css` | оформление |
